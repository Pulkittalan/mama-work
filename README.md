# Hapur District · Gram Panchayat Explorer

This version is rebuilt around click/tap selection only.

- Click or tap any coloured block on the district map.
- The selected block cutout appears enlarged in the centre of the directory.
- The map behind the directory receives a soft white fade and blur.
- The selected block's Gram Panchayat list appears with a working live search.
- Hover does not enlarge or animate the map. Hover is intentionally inactive.
- Close using ×, clicking outside the panel, or pressing Escape.
- Mobile uses a compact, vertically stacked layout.

The SVG hit areas use the same block names as the directory data, so every block opens its matching list.

Run `index.html` directly or with VS Code Live Server.
